# Lord of the rings online_CN汉化包 0.1.0-preview

非官方 Windows 英文客户端汉化初稿。包括文本、字体和 218 张中英双语地图，商城网页仍为英文。

## 附件

- Lord-of-the-rings-online_CN-0.1.0-preview.zip：汉化差异补丁，需完整解压。
- LotroZhItemEnglish-0.1.4.zip：独立物品英文名查询插件，可选。
- SHA256SUMS.txt：附件 SHA-256。

普通玩家不要把自动生成的 Source code ZIP 当作安装包。

## 安装

Windows、Python 3.11+（建议 3.12），同盘建议 45 GiB 空间。校验后运行 02 检查版本，再运行 03 安装并选择自己的游戏主目录。仅支持 install-plan.json 中的原件哈希。04 还原英文，05 处理中断事务，06 在还原后清理备份。

详细步骤见附件安装使用说明。插件独立安装与卸载，不访问游戏 DAT。
