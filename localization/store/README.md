# 商城中文文字试稿（未安装）

**2026-10-16 更新：已在工作区准备内嵌商城接入原型及新增截图文案，未安装、未连接真实商城，见 [原型说明与验证限制](EMBEDDED-PROTOTYPE.md)。目前不能称为商城已汉化。**

用户已选择优先研究**游戏内商城**，最新结论、证据和后续验证步骤见 [内嵌商城研究](EMBEDDED-RESEARCH.md)。已确认本机使用 CEF 99，并找到值得验证的调试接口路径；尚未启用接口或验证真实商城页面。下述用户脚本仍只是外部浏览器草案。

商城的网页内容不来自这次修改的 DAT 文本资源。官方的 [新版商城介绍](https://www.lotro.com/news/lotro-updated-store-de?locale=de_DE) 说明可以将商城切换到系统默认浏览器打开。

`store-zh.user.js` 是另行准备的外部浏览器用户脚本，只匹配 `https://store.lotro.com/`。当前翻译截图中的主要导航、部分促销文字、三种指定宝箱名称和速度增益名称；未知商品名称保持原文。它不代表全商城已汉化。

本脚本没有安装到浏览器，也没有接入游戏内嵌浏览器。若后续决定采用外部浏览器方案，可在支持用户脚本的浏览器环境加载该文件，再从游戏里选择“Open Store in External Browser”。现阶段不改变用户的商城打开方式。

实现只改已知的可见文字、提示和无障碍标签，不修改按钮事件、链接、商品编号、输入值、点数余额或价格，不发起网络请求。移除或停用脚本并刷新页面即可恢复原文。仍需在实际商城 DOM 中验证，当前只完成文字函数测试：

```powershell
node --test tests/store-zh.test.cjs
```
