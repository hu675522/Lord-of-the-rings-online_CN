# 汉化资源构建

本目录保存词表、翻译脚本和资源编解码构建流程。普通开发测试与完整资源重建条件见 [开发说明](../docs/DEVELOPMENT.md)，玩家使用发布附件，见 [安装说明](../docs/INSTALL.md)。

维护者的全量素材位于 full/，包含当前资源清单、文本二进制库、中英对照、字体和结构校验结果。原件、模型、运行依赖和生成物不随源码分发；缺少这些资料时，不要把完整构建脚本当作玩家安装器。

公开源码保留词表、修正规则、地图排版工具及独立英文名插件构建器。发布差异包无需玩家运行翻译模型或原生 DAT 工具。

已生成的本地素材可以只读核对：

```powershell
py -3 tools/verify_artifact_files.py --manifest localization/full/manifest.json
```
